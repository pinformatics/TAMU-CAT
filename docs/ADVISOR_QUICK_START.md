# Advisor Quick-Start

## Purpose

This guide helps advisors review advisee competency progress without needing admin import knowledge.

## Main Pages

### Advisor Dashboard

Use this as the starting point for assigned students, survey assignments, and recent notifications.

### Student Overviews

Use `Student Overviews` for an all-in-one student page. Advisors only see assigned advisees.

The detail page includes:

- basic student profile information
- advisor assignment history
- domain snapshot
- completed survey responses
- imported course competency history
- competency review notes
- detailed competency comparison
- one-student competency history CSV export

### Reports

Use reports for cohort-level and course-level trends. Filters are useful when preparing for advising meetings or program review.

## Reviewing One Advisee

1. Open `Student Overviews`.
2. Search for the student by name, email, or UIN.
3. Open the student detail page.
4. Review the domain snapshot for broad strengths and attention areas.
5. Review `Competency History` for imported course evidence.
6. Open `Detailed competencies` when you need the full cross-source comparison.
7. Download `Export history CSV` when you need a one-student history for advising notes or portfolio review.

## Understanding Sources

- Self ratings come from student survey responses.
- Advisor ratings are historical and may be retiring in some workflows.
- Course ratings come from committed course competency imports.
- Course targets are imported with course files and represent expected performance for that course.
- End-of-program targets are configured by admins and represent program-level expectations.

Course target and end-of-program target are intentionally different concepts.

## When Results Look Missing

Check:

1. Is the course import committed?
2. Has the course release date passed?
3. Is the student assigned to your advisee list?
4. Was the student matched during import?
5. Is the selected semester filter hiding older data?

If the issue looks import-related, ask an admin to review the grade import batch diagnostics.

## Exporting Advisee Data

Use `Portfolio Export` to download assigned advisees with Google Sites portfolio URLs and competency summary columns.

Use `Export history CSV` on a student overview for one student's detailed competency history across committed imports.

Student-level exports may contain FERPA-sensitive information. Use them only for a legitimate educational interest.
