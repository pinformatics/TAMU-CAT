# Semester Release Checklist

## Purpose

Use this checklist before opening a semester's competency results to students and advisors.

## Setup

- Current semester exists in `Admin > Program Setup > Semesters`.
- Tracks are correct.
- Class years are correct.
- End-of-program targets are filled for every required track and class year.
- Course release dates are configured.
- Faculty templates or Canvas export instructions have been sent.

## Import

- Every expected course file has been uploaded as a dry run.
- Every dry run has been reviewed.
- Missing competency mappings have been added or files have been corrected.
- Invalid UIN rows have been corrected.
- Invalid assessed or target levels have been corrected.
- Pending student matches have been reconciled or documented.
- Approved dry runs have been committed.
- Committed batches are assigned to the correct semester.

## Review

- `Reports > Course Competencies` shows expected courses.
- Target-met counts look reasonable by course and competency.
- Course release statuses are correct.
- `Student Overviews` has been spot-checked for several students.
- Portfolio export includes expected students and competency summaries.
- Student-level exports were created only by authorized users.

## Release

- Course release date has passed or is intentionally cleared.
- Students can see released course competency results.
- Advisors can see newly released results.
- Notifications have been queued or sent as expected.

## Archive and Cleanup

- Graduated or inactive students have the correct lifecycle state.
- Old advisor competency fields are labeled as historical where shown.
- Old local sample outputs are not committed.
- Import correction files are retained only where policy allows.
